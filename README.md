# 強化の次の一手

メイプルストーリー(JMS)の装備強化プランナー。
今の装備から、**次にどこを強化するのが一番伸びるか**を1本の軸で並べる。

👉 **https://USERNAME.github.io/REPO/**　←公開後にURLを書き換える

## できること

- スタフォ・潜在・アディ潜在・転生の炎を、**最終ダメージ換算**という共通の軸で比較する
- 1Gあたりの伸び（メル強化）と、炎1個あたりの伸び（イベント炎）を切り替えて並べる
- 期待費用・中央値・予算内に収まる確率を出す
- 装備ツールチップのスクリーンショットを**ドラッグ&ドロップで読み取る**（OCR）

## プライバシー

- 入力した装備データは**このブラウザのlocalStorageにだけ**保存される。どこにも送信しない。
- スクリーンショットの読み取りも**ブラウザの中だけ**で完結する。画像はアップロードされない。
- 外部通信はWebフォント(Google Fonts)の読み込みだけ。

## 別の端末で使う / バックアップ

設定の「データ」タブ →「JSONで書き出す」。別の端末では「JSONを読み込む」。
ブラウザの保存データを消すと入力も消えるので、たまに書き出しておく。

## データの出典

- スターフォースの確率・費用: shRoom「スターフォースシミュレーター」JMS ver4.43 (CROWN) データセット
- 潜在能力の排出率: 公開スプレッドシート「潜在能力排出率まとめ」
- 転生の炎の確率: 韓国公式の確率公開ページ / 値の計算式は namu.wiki「추가옵션」
- ダメージ式: インベン「메이플스토리「피해량」에 대한 이해3」

確率・価格は目安。価格は設定タブで自分の相場に変えられる。
